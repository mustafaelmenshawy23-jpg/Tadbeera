# Corrected recipe photo sources and offline packaging

The two corrected recipe images are downloaded during the production build into `public/images/recipes/`. Vite copies them into the built web app and Capacitor packages them into the APK. The recipe records use local `/images/recipes/` paths, so the images are available without a network connection after installation.
