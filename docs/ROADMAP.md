# خارطة تطوير تدبيرة

**القرارات المعتمدة**
- السوق المستهدف: مصر فقط.
- العملة: الجنيه المصري (EGP).
- اللغة الأساسية: العربية وواجهة RTL.
- التخزين: محلي افتراضياً ويعمل دون إنترنت.
- السحابة: مزامنة اختيارية بموافقة صريحة، وليست شرطاً لاستخدام التطبيق.

## مبادئ التنفيذ
1. لا تُبنى ميزة جديدة قبل مراجعة الموجود وإعادة استخدامه.
2. الواجهات لا تتعامل مباشرة مع تفاصيل التخزين؛ تستخدم طبقة بيانات موحدة.
3. يجب أن تعمل الوظائف الأساسية محلياً، وأن تستمر البيانات بعد إعادة تشغيل التطبيق.
4. لا يحدث رفع للبيانات إلى السحابة إلا بعد تفعيل المستخدم للمزامنة بوضوح.
5. أي أسعار أو تكاليف تقديرية يجب تمييزها بوضوح والسماح بتعديلها.
6. لا تُعتبر المهمة مكتملة إلا بعد اختبارها على Android والتحقق من عدم كسر تدفقات الميزات المرتبطة.

## تعريف الإنجاز العام
تطبيق عربي RTL يخدم الأسرة المصرية في مكان واحد: الميزانية والمصروفات، المطبخ، التسوق، المخزون، مهام المنزل والتوفير؛ يعمل دون إنترنت، مع مزامنة سحابية اختيارية وآمنة.
